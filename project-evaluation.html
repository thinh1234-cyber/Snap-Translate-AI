2. Đánh Giá Kiến Trúc

Ưu điểm

Phân tách thành phần rõ ràng

Background (service worker), Content Script, Popup, Options page — tuân thủ đúng mô hình Chrome Extension MV3.

Config tập trung

js/config.js gom selectors, timing, prompt template — dễ bảo trì khi ChatGPT thay đổi DOM.

Đa kênh AI linh hoạt

Hỗ trợ 3 channel: Web ChatGPT, Server API, Local API — phù hợp nhiều use case.

Nhược điểm

Background.js quá lớn (458 dòng)

Vi phạm Single Responsibility Principle. Cần tách thành modules: translation.js, chatgpt-bridge.js, cookie-manager.js, snap-controller.js.

Content.js "thần thánh" (501 dòng)

Xử lý cả overlay, popup UI, OCR, QR, iframe, drag, resize — nên tách thành ít nhất 3 modules riêng.

Không có State Management

Trạng thái snap mode, OCR, translation được truyền qua message rời rạc. Nên có một state machine hoặc event bus tập trung.

Phụ thuộc nặng vào DOM ChatGPT

chatgpt_automator.js dùng selectors cứng (#prompt-textarea, [data-testid="send-button"]). ChatGPT update UI = extension gãy.

Vấn đề cụ thể

Memory leak tiềm ẩn — content.js:497-499

document.onmouseup và document.onmousemove gán trực tiếp, không cleanup khi popup bị xóa. Nên dùng addEventListener/removeEventListener.

Callback hell — background.js:265-360

translateViaWebAuth có nested try-catch quá sâu, khó debug. Nên refactor thành async/await flat structure.

Hardcoded magic numbers

Nhiều con số rải rác: setTimeout(r, 3000), setTimeout(r, 2000), attempts < 3 — nên đưa vào config.js.

XSS protection tốt — content.js:464-471

Hàm escapeHtml() được sử dụng đúng chỗ, ngăn chặn injection qua OCR text và translation result.

4. Bảo Mật

Vấn đềMức độChi tiết
Cookie manipulation NGHIÊM TRỌNG background.js:81-118 — Set lại cookies chatgpt.com với sameSite: "no_restriction". Vi phạm chính sách bảo mật trình duyệt, có thể bị Chrome chặn hoặc extension bị reject khỏi Web Store.
API Key lưu ở chrome.storage.sync TRUNG BÌNH API Key được lưu đồng bộ lên Google account. Nếu tài khoản bị xâm nhập, key bị lộ. Nên dùng chrome.storage.local thay thế.
Host permissions quá rộng TRUNG BÌNH "<all_urls>" trong host_permissions — không cần thiết cho chức năng chính. Nên thu hẹp xuống các domain cụ thể.
Anti-throttling script TRUNG BÌNH chatgpt_automator.js:13-27 — Override document.visibilityState và requestAnimationFrame. Có thể bị phát hiện là hành vi bất thường.
execCommand('insertText') THẤP Đã deprecated nhưng vẫn hoạt động. Fallback innerText + dispatchEvent có thể bị ProseMirror bỏ qua.
declarativeNetRequest THẤP Dùng để bypass CSP cho chatgpt.com — hợp lý về mặt kỹ thuật nhưng có thể vi phạm ToS của ChatGPT.

Khuyến nghị bảo mật quan trọng nhất

Remove cookie manipulation và iframe embedding. Thay vào đó, sử dụng Chrome Tab Capture API kết hợp với Chrome Messaging để giao tiếp với tab ChatGPT đã mở — an toàn và tuân thủ chính sách.

5. Trải Nghiệm Người Dùng (UX/UI)

Điểm mạnh

Selection overlay trực quan

Dark dimmer + dashed border + crosshair cursor — giống công cụ screenshot chuyên nghiệp. Box-shadow 9999px là kỹ thuật thông minh.

Popup kết quả có drag + resize

Người dùng có thể di chuyển và thay đổi kích thước popup — UX tốt cho workflow đa nhiệm.

Progress indicator rõ ràng

OCR hiển thị % tiến trình, spinner animation, nút hủy tiến trình — giảm anxiety cho người dùng.

Điểm cần cải thiện

Popup HTML thiếu visual hierarchy

Popup chỉ có 3 nút đơn giản, thiếu visual feedback khi hover/focus. Nên thêm: animation khi click, loading state trên nút, tooltip hướng dẫn.

Options page thiếu responsive

Max-width 600px cố định — không tối ưu cho màn hình nhỏ hoặc tablet. Nên dùng responsive grid.

Không có onboarding flow

Người dùng mới cài sẽ bối rối: cần đăng nhập ChatGPT trước? Bật OCR ở đâu? Alt+X là gì? Nên có welcome tour sau khi cài.

Không có error recovery UX

Khi OCR thất bại hoặc ChatGPT không phản hồi, thông báo lỗi kỹ thuật khó hiểu với người dùng phổ thông. Nên có: hướng dẫn khắc phục, nút retry, link support.

Thiếu dark mode

Giao diện sáng hoàn toàn — không phù hợp người dùng làm việc ban đêm hoặc prefer dark theme.

Không có clipboard copy button

Kết quả dịch không có nút copy — người dùng phải bôi đen thủ công. Đây là tính năng cơ bản cần có.

6. Hiệu Năng

Thành phầnĐánh giáChi tiết
Tesseract.js load Nặng ~4MB traineddata (vie+eng). Load lần đầu chậm, nhưng có caching. Nên lazy-load chỉ khi user bật OCR.
Content script injection Có thể tối ưu Inject tesseract.min.js + jsQR.js vào MỌI trang (<all_urls>). Tốn tài nguyên ngay cả khi user không snap.
Anti-throttle polling Tốn CPU chatgpt_automator.js poll mỗi 500ms + focus events liên tục. Có thể gây drain pin trên laptop.
Canvas cropping Tốt Sử dụng DPR-aware cropping, chất lượng ảnh cao trên màn hình Retina/HiDPI.
Tab management Có vấn đề Tạo pinned tab ChatGPT với autoDiscardable: false — ngăn browser giải phóng RAM, có thể gây chậm máy nếu user mở nhiều tab.

Khuyến nghị hiệu năng

Chuyển content scripts từ run_at: "document_idle" sang dynamic injection — chỉ inject khi user thực sự nhấn nút Snap. Giảm ~70% resource consumption trên các trang không sử dụng.

8. Phương Án Tối Ưu

🔴 Ưu tiên cao — Cần làm ngay

R1: Loại bỏ cookie manipulation & iframe embedding

Vấn đề: Vi phạm Chrome Web Store policy, rủi ro bảo mật, không ổn định.
Giải pháp: Sử dụng chrome.tabs.sendMessage trực tiếp tới tab ChatGPT đã mở (đã có content script). Không cần iframe, không cần cookie hack.
Estimate: 2-3 ngày

R2: Tách background.js thành modules

Vấn đề: 458 dòng single file, khó maintain, khó test.
Giải pháp: Tách thành 4 modules:
  • js/modules/snap-controller.js — xử lý snap commands
  • js/modules/translation-engine.js — API calls, prompt building
  • js/modules/chatgpt-bridge.js — tab management, messaging
  • js/modules/notification-manager.js — error handling, user feedback
Estimate: 3-4 ngày

R3: Thêm automated testing

Vấn đề: 0% code coverage, mỗi lần sửa là đánh liều.
Giải pháp:
  • Unit tests: Jest cho config.js, prompt building, escapeHtml
  • Integration: chrome-remote-interface cho message passing
  • E2E: Playwright với Chrome extension support
Estimate: 5-7 ngày (setup + viết test cốt lõi)

🟡 Ưu tiên trung bình — Nên làm trong sprint tới

R4: Lazy-load content scripts

Vấn đề: Tesseract + jsQR load trên mọi trang, tốn RAM.
Giải pháp: Bỏ content_scripts khỏi manifest, chỉ inject động khi user nhấn Snap. Giảm ~70% memory footprint.
Estimate: 1-2 ngày

R5: Thêm onboarding flow

Vấn đề: User mới không biết cách sử dụng.
Giải pháp: Tạo html/onboarding.html hiển thị lần đầu cài đặt: hướng dẫn 3 bước (đăng nhập ChatGPT → nhấn Alt+X → xem kết quả). Lưu flag hasSeenOnboarding trong storage.
Estimate: 1-2 ngày

R6: Thêm copy button + export kết quả

Vấn đề: Không có cách nhanh để copy kết quả dịch.
Giải pháp: Thêm nút 📋 Copy bên cạnh mỗi kết quả. Hỗ trợ export TXT/CSV cho batch translation.
Estimate: 0.5 ngày

R7: Dark mode support

Vấn đề: Chỉ có light mode.
Giải pháp: CSS variables + prefers-color-scheme media query. Toggle trong options page.
Estimate: 1-2 ngày

🟢 Ưu tiên thấp — Có thể làm sau

R8: Chuyển sang TypeScript

Lợi ích: Type safety, autocomplete, giảm runtime errors. Bắt đầu với JSDoc comments trước khi migrate hoàn toàn.
Estimate: 7-10 ngày

R9: Analytics & crash reporting

Lợi ích: Hiểu user behavior, phát hiện lỗi production. Dùng Plausible (privacy-friendly) hoặc tự-host.
Estimate: 2-3 ngày

R10: Publish lên Chrome Web Store

Yêu cầu trước: Remove cookie manipulation, thu hẹp permissions, thêm privacy policy, viết mô tả chuyên nghiệp.
Estimate: 3-5 ngày (chuẩn bị + review)
