# Web Automation Controller

## Component Description

Manages complex interactions with external AI web interfaces (like ChatGPT). It coordinates the execution of automation scripts that simulate user actions, such as text input and button clicks, while monitoring the page state to ensure synchronization with the AI's response lifecycle.
